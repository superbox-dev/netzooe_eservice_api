# AGENTS.md

Async Python client (`aiohttp`) for the unofficial Netz Oberösterreich eService portal API (`eservice.netzooe.at`).
Published on PyPI and used by the Home Assistant integration.

## Commands

```bash
./scripts/setup.sh                   # install deps + prek hooks
uv run ruff format                   # format
./scripts/lint.sh                    # all linters (ruff, ty, yamllint, rumdl)
uv run pytest                        # tests, 100% coverage required
uv run pytest --snapshot-update      # regenerate syrupy snapshots, then review the diff
```

Run `uv run ruff format`, `./scripts/lint.sh` and `uv run pytest` before finishing. Python 3.13 is the minimum.

## Rules

- **No breaking changes** to anything public: `NetzOOEeServiceAPI` methods (signatures, return values, behaviour),
  `Pod`, constants, enum members and exceptions. Renames keep the old name as an alias; new parameters are optional
  with a default that keeps the old behaviour. A crash may become an `APIError`, but a working call must keep working.
- No `# noqa`, no `# type: ignore`, no new `ruff.toml` ignores. Fix the code instead.
- Every `.py` file starts with `# Copyright 2026 Michael Hacker` and `# SPDX-License-Identifier: Apache-2.0`.
- Never use real credentials or customer data. Use placeholders like `"test"` and constants like `MOCK_CREDENTIAL`.
- Never edit `netzooe_eservice_api/version.py` (generated by `setuptools-scm`) or `coverage-badge.svg` (CI).

## Architecture

- `api.py`: `NetzOOEeServiceAPI` and the `Pod` `TypedDict`. `login()` posts to `/service/j_security_check`, then
  `GET /service/v1.0/session` sets the `XSRF-TOKEN` cookie, sent as `x-xsrf-token` header. `_request()` logs in
  lazily, retries once after re-login on `401` and maps errors to the exceptions in `error.py`.
  A passed `session` is never closed; an own session is closed on `logout()` and on errors.
- `constants.py`: URLs, headers and enums. Enum values are the exact strings the portal expects.
- Public methods take `snake_case` parameters, map them to the portal's `camelCase` inside the method, only send
  optional fields when set and return the raw JSON. Enum parameters accept a member, a list of members or `None`.
- Tests: mock HTTP with `aioresponses` (`create_client` / `create_logged_in_client`) and assert the recorded
  requests with the `snapshot` fixture. Cover happy and unhappy paths.

## Changelog and git

- Every user-visible change needs an entry under `## [Unreleased]` in `CHANGELOG.md` (Keep a Changelog, past tense,
  identifiers in backticks, issues as `([Issue #67][issue-67])`).
- Work on `develop`, `main` is the release branch. Only commit or push when asked.
